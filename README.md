# Feyaaz Chishty portfolio

Next.js App Router portfolio for [Feyaaz Chishty](https://github.com/Feyfeyyy).

## Requirements

- Node.js 20 or newer
- npm

## Setup

```bash
npm install
```

Or with Make:

```bash
make install
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
make dev
```

## Production build

Create a local production build:

```bash
npm run build
```

Serve that build:

```bash
npm run start
```

```bash
make build
make start
```

## Lint

```bash
npm run lint
```

```bash
make lint
```
